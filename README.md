# بورتفوليو Mohamed Ali — دليل التعديل

## الملفات وكل واحد بيعمل إيه

```
mohamed-portfolio/
├── index.html        الصفحة الرئيسية: بتحمّل باقي الملفات بالترتيب (نادرًا هتعدّل فيها)
├── css/
│   └── style.css     الشكل: ألوان، خطوط، أحجام، أماكن الكلام
└── js/
    ├── config.js     بياناتك: الإيميل، الروابط، النبذة، المشاريع  ← أسهل ملف للتعديل
    ├── panels.js     رسمة كل لوحة مشروع (الرسمة + الاسم + الوصف)
    ├── scene.js      الـ3D (الكرة واللوحات والكاميرا) + حركة الكلام مع السكرول
    ├── logo.js       اللوجو: المنارة + دوران الشعاع + تتبّع الماوس
    └── app.js        هيكل الصفحة (الأقسام) بـ React
```

## عايز أعدّل إيه؟

| عايز | روح على | عدّل |
|---|---|---|
| الإيميل / GitHub / الموقع / المكان / النبذة | `js/config.js` | كائن `SITE` |
| اسم مشروع أو وصفه أو تقنياته | `js/config.js` | مصفوفة `PROJECTS` |
| رابط مشروع معيّن | `js/config.js` | الحقل `link` جوه المشروع |
| إضافة مشروع جديد | `js/config.js` | زوّد سطر جديد في `PROJECTS` (اللوحة والاسم بيتعملوا لوحدهم) |
| لون البرتقالي أو الخلفية أو الخطوط | `css/style.css` | المتغيرات أول الملف (`--or`, `--bg`...) |
| حجم الكلام الكبير | `css/style.css` | `.ht` للهيرو، `.big` للجمل، `.pn` لأسماء المشاريع |
| كلمات الهيرو (creative / web / developer) أو الجمل الكبيرة | `js/app.js` | جوه `<h1 className="ht">` وأقسام `STATEMENT` و`CONTACT` |
| شكل اللوجو (المنارة والشعاع) | `js/logo.js` | كود الـSVG (الحروف من `SITE.initials`) |
| شاشة الدخول (عدّاد + كرة بتكبر) | `js/app.js` و`css/style.css` | دالة `Intro` (أقل مدة `2.2`) والكلاس `.intro` |
| سرعة انتقال الكرة لمكانها بعد العدّاد | `js/scene.js` | `it/.9` في `loop` |
| منطقة ثبات الكلام المتحرك في وسط الشاشة | `js/scene.js` | الرقم `.22` في `loop` (أكبر = الكلام ثابت أكتر) |
| حجم كلام المهارات | `css/style.css` | `.sr` (الصفوف) و`.sk .big` (العنوان) |
| نقاط التجاوب (موبايل، تابلت، لاندسكيب، شاشات كبيرة) | `css/style.css` | قسم `RESPONSIVE` في آخر الملف |
| المهارات (إضافة/حذف) | `js/config.js` | مصفوفة `SKILLS` |
| أيقونة زرار Menu في الموبايل | `css/style.css` | `.mi` (الكلمة بتظهر في الكمبيوتر بس) |
| سرعة دوران الشعاع | `js/logo.js` | الرقم `.9` في `draw` (أكبر = أسرع) |
| قوة تتبّع الماوس (ميل المنارة وميل الشعاع) | `js/logo.js` | الأرقام `2.5` و`7` و`16` في `draw` |
| حجم اللوجو | `css/style.css` | `.logo svg` (الارتفاع) |
| سرعة الطيران بين اللوحات | `js/scene.js` | الرقم `Z` (أكبر = أسرع) |
| نعومة السكرول | `js/scene.js` | الرقم `.075` في `loop` (أصغر = أنعم) |
| لون الكرة | `js/scene.js` | `vec3(1.,.36,.04)` جوه الـshader |
| شكل لوحة المشروع | `js/panels.js` | دالة `paint` |
| سرعة/اتجاه حركة كلمة | `js/app.js` | `data-sp` على العنصر (سالب/موجب = اتجاه) |

## ملاحظات

- **التشغيل:** افتح `index.html` في المتصفح مباشرة، أو ارفع المجلد كله على GitHub Pages. لازم إنترنت لأن React وThree.js والخطوط بتتحمّل من CDN.
- **على GitHub Pages:** ارفع كل المحتويات (مع الحفاظ على فولدري `css` و`js`) وخلّي `index.html` في الجذر.
- **اللوحات الأولى:** الهيرو بيعرض أول 3 مشاريع في `PROJECTS`، وقسم Work بيعرض كلهم.
- **لما تعدّل:** عدّل ملف واحد وحدّث الصفحة (Ctrl+Shift+R لتجاوز الكاش).
